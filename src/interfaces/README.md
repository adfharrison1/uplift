# Interfaces & Composition Layer (`src/interfaces/`)

## Purpose

`src/interfaces/` is the outer presentation, CLI, local dev middleware, and dependency-wiring shell of **Uplift**:

- **`cli/queryLogs.ts`**: Command-line utility (`npm run logs:query`) for filtering active and compacted session logs by `--level`, `--category`, `--actor`, `--actee`, `--action`, `--min-tick`, `--max-tick`, and `--has-ai-reasoning`.
- **`vite/localDiskBridgePlugin.ts`**: Vite dev-server middleware mounting `/api/telemetry/*`, `/api/saves/*`, `/api/scene-blueprints/:stageId`, and `/api/character-visuals/:characterId` with a `256 KiB` body cap (`413`), path-traversal rejection, atomic temp-file-and-rename writes, and Zod `safeParse` validation (`400`).
- **`three/`**: Three.js 60 FPS WebGL stage-paint chiaroscuro scene graph & parametric kitbash builders (`StageKitbashBuilders.ts`, `ChiaroscuroStageRenderer.ts`), featuring a shared 3-band stepped toon gradient `DataTexture`, parametric architectural motifs, character posture/wardrobe kitbashers, `userData.semanticId` tagging, raycast lookup, and `disposeSceneGraph`. Epoch 2+ travel cabins reuse this path (stage swap + live `TravelSurfaceCueBlueprint` kitbash deltas on embark / watch ticks).
- **`hud/`**: In-Game `F3` Stage, Lighting & Wardrobe Inspector controller and Agent DOM Mirror (`StageInspectorDomMirror.ts`) synchronizing `data-active-space-id`, `data-hovered-semantic-id`, `data-selected-semantic-id`, `data-debug-paused`, `data-camera-mode`, and `globalThis.__UPLIFT_STAGE_INSPECTOR__`, plus pure live blueprint mutators.
- **`composition/`**: The only page. Root `index.html` loads `composition/browserMain.ts`. `shellDocument.ts` stacks `viewport`, an empty `diegetic` layer, and `dev-hud`. `browserMain.ts` creates one `WebGLRenderer` (`antialias: false`, `alpha: false`), caps the pixel ratio at `1`, and calls `PlaySession.frame` once per animation frame. `playInput.ts` routes waypoint commands, floor and portal pointers, pause, and free-cam. `stageLabPanel.ts` is the paused stage panel. The proving-slice pack is named only in the startup call at the bottom of `browserMain.ts`.

## Current Module Inventory

- `cli/queryLogs.ts` — `parseQueryCliArgs` and `executeLogQuery` CLI runner.
- `vite/localDiskBridgePlugin.ts` — `handleLocalDiskBridgeRequest`, `isBridgeApiUrl`, and `localDiskBridgePlugin`.
- `three/StageKitbashBuilders.ts` — `getSharedChiaroscuroGradientMap`, `createChiaroscuroToonMaterial`, `buildWallMotifGroup`, `buildStagePropGroup`, `buildCharacterKitbashGroup`, and re-exported visual blueprint types/schemas for `src/content/scene/`.
- `three/ChiaroscuroStageRenderer.ts` — `buildStageSceneGraph`, `applyRenderFrameToScene`, `resolveSemanticIdFromObject`, `findObjectBySemanticId`, and `disposeSceneGraph`.
- `hud/StageInspectorDomMirror.ts` — `StageInspectorDomMirror`, `InMemoryDomAttributeSink`, `buildInspectableTargetCatalog`, `upsertWallSegmentMotif`, `removeWallSegmentMotif`, `updateStageLight`, `updateCameraVolumeFraming`, `updateEpochVisualTheme`, and `updateCharacterVisualSlot`.
- `composition/shellDocument.ts` — `createCampaignShell`, `SHELL_LAYER_ORDER`, `cappedDevicePixelRatio`, and `prefersReducedMotion`. The layer order is `viewport`, `diegetic`, `dev-hud`. The diegetic plan has no children. The canvas `aria-label` is `Uplift`. `registerDevHudPanel` throws when the id is empty or already registered, and the first panel stays. `elementPlan()` is the model `mount` walks.
- `composition/browserMain.ts` — `bootCampaignPage(document, window, launch)`. `CampaignLaunch` is the pack, the stage map, the character visuals, the theme, and the focus entity id. One renderer and one animation frame. Each frame passes `prefers-reduced-motion` and the window aspect (`innerWidth / innerHeight`, or `1` when the height is `0`). In-memory telemetry (cap `2048`) and saves live in this file because the infrastructure adapters import `node:fs`. A released stage id disposes the scene graph, then the resident stage is mounted. The lab selection is copied onto the render frame before it is drawn. The startup call runs only when `document` is defined and passes `STARTER_HOLD_PACK`, `STARTER_HOLD_STAGE_DIRECTORY`, `STARTER_HOLD_CHARACTER_VISUALS`, `DEFAULT_HIGHGLASS_VISUAL_THEME`, and `char_player_operative`.
- `composition/playInput.ts` — `createPlayInput`. The bindings are `waypoint` (always active), then `portal`, then `floor`. A binding runs only when `when()` is true, and a `handle()` that returns true consumes the pointer. Portal and floor raycasts run only while unpaused. A floor hit is stage-local. The binding adds the resident space origin before `clickFloor`, and it skips that call when the focus entity is not in the drawn space. A paused pointer picks and does not call those raycasts. `F3` and the backtick key (`Backquote`) toggle `setPaused` and `setCameraDeAnchored` together. Arrow keys change `freeCamOffset` by `0.5` m only while paused. The returned status is text on the `data-play-status` paragraph.
- `composition/stageLabPanel.ts` — `createStageLab`. A paused pick updates `StageInspectorDomMirror` and `selection()`. The panel offers `open`, `ajar`, `closed`, and `barred` for the selected portal prop. `saveStage` and `saveVisual` parse with the existing Zod schemas, then `PUT` `/api/scene-blueprints/:stageId` or `/api/character-visuals/:characterId`.
- `index.ts` — Public interfaces layer barrel. It does not re-export `composition/`, so importing the barrel does not boot the page.
