# Agent Guide — Interfaces & Composition Layer (`src/interfaces/`)

## Strict Guardrails (Enforced by `npm run verify`)

1. **Composition Root & Server-Only Node Imports**: Keep Node `node:fs` / `node:http` adapters inside `src/interfaces/cli/` and `src/interfaces/vite/` (used by CLI scripts and `vite.config.ts`). Browser-side Three.js and HUD modules in `src/interfaces/three/` and `src/interfaces/hud/` must communicate with disk via `/api/telemetry`, `/api/saves`, `/api/scene-blueprints`, and `/api/character-visuals` or injected ports.
2. **Zod Boundary Validation & Atomic Writes**: Validate all incoming HTTP and CLI payloads using Zod schemas and `safeParseJsonWithSchema`, reject any `%`, `/`, `\`, or `..` in URL asset/slot IDs, and use `infrastructure/persistence/safeLocalFiles.ts` for visual asset reads, size inspection and atomic writes. Keep each configured asset root separate. Reject linked roots, parents, destination files and temporary files, including dangling links. Serialize validated data before exclusive temporary creation and replacement; never create directories for GET.
3. **Thin Three.js Adapter, `semanticId` Tagging & GPU Disposal**: Keep `src/interfaces/three/` focused on translating pure `RenderFrame` data and 3-Layer Visual Blueprints (`EpochVisualTheme`, `StageSceneBlueprint`, `CharacterVisualBlueprint`) into Three.js `Scene` updates at 60 FPS. Stamp every generated `THREE.Object3D` and `THREE.Mesh` with `userData.semanticId`, preserve base warm emissives on unselected meshes, and call `disposeSceneGraph(root)` before reloading stages so geometries and materials never leak. Epoch 2+ travel cabins are the same kitbash path: swap via `disposeSceneGraph`, and apply `TravelSurfaceCueBlueprint` visual deltas (mud, extra gazette, empty seat, blackout shutters) on embark / watch ticks — never allocate new materials per 60Hz frame.
4. **Agent DOM Mirror (`StageInspectorDomMirror`)**: Always keep `data-active-space-id`, `data-hovered-semantic-id`, `data-selected-semantic-id`, `data-debug-paused`, `data-camera-mode`, and `globalThis.__UPLIFT_STAGE_INSPECTOR__` synchronized so live browser inspection tools (`cursor-ide-browser`) can read the exact 3D surface or character part under inspection.
5. **Zero `any`**: Both implicit and explicit `any` are forbidden across all CLI, Vite, UI, Three.js, and composition files.

## Campaign page

- Keep one root `index.html`, one canvas, one `WebGLRenderer`, and one `requestAnimationFrame` loop in `composition/browserMain.ts`. A later lab calls `registerDevHudPanel` and appends a `PlayBinding` in `composition/playInput.ts`. It does not add a document, a canvas, or a frame loop.
- `bootCampaignPage` takes a `CampaignLaunch`. Name a content pack only in the startup call at the bottom of `browserMain.ts`, behind `typeof document !== 'undefined'`. The proving-slice call passes `STARTER_HOLD_PACK`, `new Map(Object.entries(STARTER_HOLD_STAGE_DIRECTORY))`, `STARTER_HOLD_CHARACTER_VISUALS`, `DEFAULT_HIGHGLASS_VISUAL_THEME`, and `char_player_operative`. Do not export `browserMain.ts` from `src/interfaces/index.ts`.
- Do not import `node:fs` from `browserMain.ts`. Browser telemetry and saves are the in-file port implementations. Stage-lab disk writes use `createBridgeSaveTransport` for `PUT` on the existing `/api/scene-blueprints/:stageId` and `/api/character-visuals/:characterId` routes after `StageSceneBlueprintSchema` or `CharacterVisualBlueprintSchema` parses.
- Pass `prefersReducedMotion` and the window aspect on every `PlaySession.frame`. Cap `devicePixelRatio` with `cappedDevicePixelRatio`. Build the stage graph with `buildStageSceneGraph` and tear it down with `disposeSceneGraph` when `releasedStageId` is non-null. Apply a focus change as soon as `setFocusEntity` returns that id. Do not wait for the next frame, which reports no release once the resident stage already matches.
- Raycast on pointer down, not per frame. Skip a hit when the object or any parent has `visible === false`. Test the portal binding before the floor binding. A floor hit is stage-local. `playInput.ts` adds the resident space origin with `toWorld` before `clickFloor`, and it skips that call when `focusSharesDrawnSpace()` is false. A paused pointer calls the pick raycast only. Waypoint ids are cached per space. Focus buttons list the entities in the focus entity's space, and `sync()` rebuilds those buttons only when the returned arrays change. Free-cam de-anchor does not build inspector cards.
- Leave the diegetic layer empty. Waypoint commands and the stage lab attach to the `stage` dev-HUD panel. Status is the text of `data-play-status`, not color alone.

## Visual asset disk operations

`handleLocalDiskBridgeRequest` is an in-process I/O dispatcher, not an HTTP trust boundary. Its optional sixth `LocalFileOptions` argument supplies trusted filesystem dependencies for real-directory fault tests; never populate those dependencies from a request. Stage and character routes retain their ID/schema validation, 404 for absent assets and 413 byte limits. Inspect the confined file size before reading an asset. Unsafe paths return 400 with `Unsafe storage path`; no filesystem paths appear in that policy error. Browser consumers continue to use the existing PUT routes.

## Dev token and save status

- Generate the dev token with `node:crypto` inside the server-only plugin, once per server run. Inject it only into dev HTML as `uplift-bridge-token`; renew it on restart. Do not persist it, log it, put it in URLs or emit it into production HTML.
- Use `composition/bridgeTransport.ts` for browser stage/character writes. Read the served token, send JSON plus `X-Uplift-Bridge-Token`, accept only the existing relative asset paths, require same-origin fetch and reject redirects. Keep the lab's void callback contract and contain asynchronous failures. Queue explicit saves in order; never automatically retry a failed write.
- `browserMain.ts` owns the dedicated save-status paragraph and passes its sink to the transport. Use `textContent`, `data-bridge-save-status`, `role=status`, `aria-live=polite` and `aria-atomic=true`. Keep it separate from `data-play-status` so input/frame synchronization cannot erase errors. Only the latest explicit attempt may update completion status. Preserve edited state and provide reload guidance for missing/stale credentials; do not display response bodies, exceptions or tokens.
- Token delivery and client headers are not evidence of server authorization. Keep production-build absence and real dev restart checks alongside browser transport tests.
