# Domain Layer (`src/domain/`)

## Purpose

`src/domain/` is the pure TypeScript heart of **Uplift**. It defines the deterministic simulation primitives, Zod-validated domain schemas and ports, epoch-agnostic plug-and-play module registries, continuous 60Hz spatial kinematics and human-paced cognitive phases, pure `WorldEffect` reducers, and Dual-Ledger `CivilizationLegacyState` continuity models.

It has **zero outward dependencies** on application, infrastructure, interfaces, content, Three.js, model runtimes, or DOM/WebGL globals. Registry schemas describe accepted data, not complete gameplay consumers. Emergency, pressure/discovery and orbital reducers exist, while the proving pack does not supply content for those systems. Campaign maturation and a configurable epoch-ladder contract remain in [design intent](../../DESIGN_NOTES.md).

## Current Module Inventory

- `core/SeededRandom.ts` — Deterministic 32-bit Xorshift PRNG with one-shot `splitmix32` mixing for fresh numeric seeds and raw serialized-state restoration through `fromState` (`nextUint32`, `nextFloat`, `nextInt` with rejection sampling, `choose`, `getState`).
- `core/StateSliceRegistry.ts` — Type-safe plugin state descriptors (`StateSliceKey<T>`, `defineStateSlice`, `StateSliceRegistry`, and immutable `StateSliceStore`). Defaults, writes, append rows and restored snapshots accept only plain JSON: finite numbers, strings, booleans, null, dense arrays and plain objects; special objects, cycles, unsupported values and unsafe keys are rejected. Private record copies have no inherited properties, and array copies own each element, so inherited setters cannot drop data and prototype-named ids cannot skip migration. Optional validation-only key and row schemas preserve values through structural comparison, including when an inherited serialization hook exists. A registry-bound unset slice uses the registered default, and a stored slice keeps its captured validator authority. Optional positive versions and one-step migration callbacks validate known older slices before restore; unknown slices retain their raw value and version. `toSnapshot` keeps raw values, while `toVersionMap` carries versions above one separately. Values are private deeply frozen copies and `get` shares stable references. Define appendable keys with `defineStateSlice`; `appendSlice` avoids traversing earlier rows, while full reads, snapshots and general `updateSlice` scale with the collection. Whole-array schemas disallow fast append, and the public constructor accepts no raw entries.
- `telemetry/SessionTelemetryPort.ts` — Epoch-agnostic session telemetry schemas and ports (`TelemetryClock`, `TelemetryLevelSchema`, `AiReasoningTraceSchema`, `TelemetryEventInputSchema`, `TelemetryEntrySchema`, `CompactedTelemetryDigestSchema`, `TelemetryStreamRecordSchema`, `PRESERVED_TELEMETRY_CATEGORIES`, `isHighSignalTelemetryEntry`, `SessionTelemetryPort`).
- `persistence/SaveSlotRepositoryPort.ts` — Epoch-agnostic multi-session save/load schemas and ports (`SAVE_SLOT_SCHEMA_VERSION`, `SaveSlotIdSchema`, `RngStateSchema`, `SaveSlotMetadataSchema`, `SaveSlotEnvelopeSchema`, `SaveSlotWriteInputSchema`, `validateSaveSlotId`, `SaveSlotRepositoryPort`). Schema-2 write inputs, envelopes and metadata require nonempty `packId` and positive `packVersion`; identity-free and schema-1 envelopes cannot load.
- `persistence/WorldStateCodec.ts` — Strict, versioned serialized-world codec. `encodeWorldState` produces a private plain-JSON snapshot with version 2 and excludes the separate state-slice store; `decodeWorldStateSnapshot` validates nested world fields, checks epoch/tick against the envelope, and migrates a synthetic version-1 snapshot by changing only its marker. Missing or future versions, extra fields, unsafe record keys, lossy JSON values and orbital availability above capacity fail before a world is returned. The coordinator uses the codec for save/load while keeping custom slices and their version map separate.
- `registries/EpochBlueprints.ts` — Epoch-agnostic Zod v4 schemas and types for `SpaceNodeBlueprint`, `WaypointBlueprint` (optional same-space `neighborWaypointIds`), `PropBlueprint` (optional portal target pair; `portalState` alone is hinge/acoustic), `CharacterBlueprint` (with `InertiaPillar`, `emergencyVice`, and optional `separationWeight` `0..1`), `OfficeBlueprint`, `QuietClaimBlueprint`, `RivalCivBlueprint`, `TrajectoryThreadBlueprint`, `ChannelMediumBlueprint`, `EmergencyStateBlueprint`, `OrbitalPassBlueprint`, `BehaviorModule` (with human-paced deliberation/dwell/cooldown durations), `IllicitInstrumentType`, `PressureStockType`, and `DiscoveryLayer`. `EpochModulePackInput` requires `packId`, positive `packVersion` and an explicit versioned `imports` list. `hasPortalNavigationEdge` is true only when both portal target ids are set. `validateEntityId` exposes the lowercase render-token rule; character registration and snapshot decoding do not yet invoke it.
- `registries/EpochModuleRegistry.ts` — Declarative module registry enforcing global ID uniqueness, spatial/entity cross-reference integrity, waypoint neighbor and portal-target checks, explicit-neighbor degree, and Kahn's algorithm topological sort with cycle detection for `BehaviorModule` dependencies. The first pack binds a primary epoch/pack identity; later packs must match its target epoch and declared import identity/version. Failed pack registration restores blueprints, and direct registration cannot mutate a bound registry. `getPrimaryPackIdentity()` returns the retained primary identity. `getAllSpaces()` lists registered spaces with `kind` and waypoints. Omitted character `separationWeight` is stored as `1`.
- `simulation/WorldState.ts` — Immutable `WorldState`, `SimulationPacingConfig` (`DEFAULT_GAMEPLAY_PACING_CONFIG` and `FAST_EVAL_PACING_CONFIG`), `CognitivePhase`, `PendingStimulus`, `WaypointTarget`, optional entity `separationWeight` (omitted means `1`), and discriminated-union `WorldEffectSchema` including `set_separation_weight`. Initial world creation retains an immutable supplied slice store, including its version metadata.
- `simulation/WorldEffectReducer.ts` — Pure deterministic `applyWorldEffects(state, effects)` reducer with exponential stimulus hop backoff (`baseDigestionDelaySeconds * cascadeBackoffFactor^cascadeHopCount`), `maxAutonomousCascadeHops` gating (`awaiting_trigger` / `release_external_trigger`), pressure stock clamping, discovery layers, inertia pillar collapse, emergency vice compounding, orbital pass & `Slingshot`/`Burn` delta spend, audio cues (`groundside`/`lace`), legacy scars, and `set_separation_weight`.
- `simulation/WaypointNavigator.ts` — Deterministic `planWaypointPath` (breadth-first, ascending waypoint-id expansion, passable portals only) and `truncatePathAtClosedPortals` (first hop is the entity's current waypoint, then the rest of `activePath`).
- `simulation/SpatialHashGrid.ts` — 2 meter XZ hash. A `0.75` m query reads the 3×3 neighborhood and returns ids in ascending order. Bodies whose space the directory marks `off_stage_region` are not inserted. An omitted directory inserts every body.
- `simulation/KinematicsEngine.ts` — Continuous 60Hz `stepKinematics(state, dtSeconds, spaceKinds?)` engine advancing spatial polyline paths (`<= 1e-6m` zero-segment guard, exact waypoint coordinate snapping, intra-frame leftover distance carry, and ordered `WaypointArrivalEvent` emission) alongside human-paced cognitive timers (`deliberating -> moving -> performing_dwell -> cooldown -> idle|awaiting_trigger`) with single-pass zero-duration waterfalling under `FAST_EVAL_PACING_CONFIG`. Moving embodied entities in the same space take a weight-scaled XZ slide from start-of-step positions. An omitted `spaceKinds` map embodies every entity. Weight `0` keeps authored spacing.
- `legacy/CivilizationLegacyState.ts` — Dual-Ledger `CivilizationLegacyState` (`materialScars` vs. `veilScars`, `communicationsBackboneControllerId`, `lineageMutations`), `civilizationLegacyFromRecordedScars`, `recordScarInLegacyState`, `legacyStateToRecord` / `parseLegacyState`, strict `applyLegacyToCharacterBlueprints`, and pure `resolveRuntimeLegacyCharacterBlueprints`. Both mutation paths share ordered `add | multiply | clamp | override` logic, reject conflicts, unknown targets and intermediate non-finite arithmetic, and leave inputs unchanged. The runtime path saturates only finite final drives outside `[0, 1]` and returns one `LegacyDriveClampNote` per affected character and drive; the strict path rejects those final values.
- `index.ts` — Public barrel exporting all domain primitives, registries, simulation reducers/kinematics, legacy state helpers, schemas, and ports.

## Registry vocabulary and orbital reducer contracts

The character tier mapping is Tier 1 `utility_schemer`, Tier 2 `role_routine`, Tier 3 `ambient_crowd`. `InertiaPillar` kinds are `doctrine`, `constituency`, `debt`, `temper` and `ignorance`. These are schema vocabularies, not proof of a full AI implementation for every tier. Written voice profiles and public/private drive contradictions remain [design intent](../../DESIGN_NOTES.md).

`OfficeBlueprint` carries `institutionalLineageId`, `pretextFamilies` and `stipendPerTick`; `RivalCivBlueprint` carries `orbitalOffsetTicks` and `spoofMode`. `ChannelMediumBlueprint` carries `baseTransitTicks`, `interceptionRisk` and `forgeryDifficulty`. `TrajectoryThreadBlueprint` carries `dualUseCeiling` and optional `primaryCandidateLineageId` / `substituteCandidateLineageId`. These contracts accept data; they do not implement stipends, transit, spoofing or martyrdom gameplay.

`OrbitalPassRuntimeState` carries phase, `availableDelta`, `maxDelta` and `activeBurn`. The shipped `advance_orbital_pass` reducer adds the effect's `deltaRegen`, caps the result at `maxDelta`, and clears `activeBurn` outside `zenith`. `spend_orbital_delta` throws for `burn` unless the phase is `zenith`, throws for insufficient Delta, and sets the phase to `zenith` for `slingshot`. These are callable reducer contracts; the proving pack does not drive a playable orbital loop.
