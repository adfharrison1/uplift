# Application Layer (`src/application/`)

## Purpose

`src/application/` orchestrates use cases between the outer adapters (`src/interfaces/`, `src/infrastructure/`) and the inner simulation core (`src/domain/`).

Responsibilities include:

- Coordinating the continuous 60 FPS kinematics step (`stepFrame`), discrete `WorldEffect` dispatch (`dispatchEffects`), and anti-thundering-herd round-robin cognitive scheduler (`pulseCognitiveScheduler`) with full pause support for In-Game Debug Mode and fast-eval overrides (`FAST_EVAL_PACING_CONFIG`).
- Managing Dual-Ledger `CivilizationLegacyState` inheritance on epoch startup, in-epoch scar accumulation (`exportLegacyState`), and atomic multi-session save/load snapshots (`saveToSlot`, `loadFromSlot`) via `SaveSlotRepositoryPort`. Startup and load resolve finite legacy drive overflow into bounded character blueprints and retain clamp notes; load keeps the saved world snapshot unchanged and records `load_slot` before publishing restored state.
- Emitting structured session telemetry (`SessionTelemetryPort`) for kinematics arrivals, cognitive phase transitions, frame `dt` clamping, world effects, and persistence operations.
- Defining the Zod-validated **3-Layer Encoded Visual Authoring Framework** (`EpochVisualTheme`, `StageSceneBlueprint`, `CameraVolumeBlueprint`, `CharacterVisualBlueprint`, and deterministic `semanticId` helpers) in `rendering/SceneVisualBlueprints.ts`.
- Computing pure, WebGL-independent render frames (`RenderFrameBuilder` in `rendering/RenderFrameBuilder.ts`) for the volume-aware 3rd-person fixed-orientation tracking camera, critically damped spring transitions, Emergency/Zenith tilts (with `reduceMotionAndFlashing` accessibility clamp), `F3` De-Anchored Free-Cam (`+0.40` desaturation), behind-camera-guarded 3D-to-NDC `DebugInspectorCard` projection, and `AgentDomMirrorState`.
- Hosting one campaign launch in `shell/PlaySession.ts`. The launch is a stage directory keyed by `spaceId`, character visuals, a theme, and a focus entity. `frame` calls `stepFrame` once, then `pulseCognitiveScheduler` once, then resolves the resident stage. It builds one render frame when a stage is resident, and returns a null frame when none is. A space with no stage keeps the previous stage and sets status `missing_stage`. Each drawn space has an origin: the center of its waypoints on X and Z, with Y at 0 (`rendering/SpaceFrame.ts`). Entity and prop positions subtract that origin. A floor point is world meters, and a point farther than `FLOOR_WAYPOINT_RADIUS_METERS` (`1.5`) from every waypoint in the focus entity's space does not move. A waypoint whose local XZ is outside the stage footprint rejects the launch. Paused move and portal requests do not dispatch. The proving-slice visuals (`STARTER_HOLD_CHARACTER_VISUALS`, `STARTER_HOLD_STAGE_DIRECTORY`) are passed in from outside this layer.

The browser composition currently injects in-memory telemetry and save ports. These coordinator capabilities do not establish browser-to-disk logging or persistent player saves. Floor clicks and waypoint requests are development controls. No model worker or campaign maturation coordinator is implemented here.

## Current Module Inventory

- `simulation/SimulationCoordinator.ts` — Application simulation coordinator wiring `EpochModuleRegistry`, `stepKinematics`, `applyWorldEffects`, round-robin `pulseCognitiveScheduler`, `CivilizationLegacyState`, `SessionTelemetryPort`, and `SaveSlotRepositoryPort`. It exposes immutable `getLegacyClampNotes()` diagnostics and records one structured `legacy_drive_clamped` warning per saturation; failed warning writes do not stop startup/load or later notes. `requestWaypointMove` plans a portal-gated path and dispatches only `move_entity_to_waypoint`. `requestSetPortalState` dispatches `update_prop_state`. On an unpaused `stepFrame` with `dtSeconds > 0`, closed-portal hops are truncated before kinematics, which receives a space-kind directory built from `getAllSpaces()` at construction. Spawn copies `separationWeight` (`1` when omitted).
- `rendering/SceneVisualBlueprints.ts` — Layer 1–3 Zod schemas (`EpochVisualThemeSchema`, `StageSceneBlueprintSchema`, `StagePropVisualBlueprintSchema`, `CameraVolumeBlueprintSchema`, `CharacterVisualBlueprintSchema`), `resolveCharacterVisualForTheme`, and deterministic `semanticId` formatters/validators.
- `rendering/RenderFrameBuilder.ts` — Pure `RenderFrameBuilder`, `selectActiveCameraVolume`, `stepCriticallyDampedSpring`, and `projectWorldToNdc`. `spaceOrigin` shifts entity and prop poses into the stage frame. `focusPositionOverride` stays stage-local.
- `rendering/SpaceFrame.ts` — `spaceOrigin`, `toLocal`, `toWorld`, and `assertWaypointsOnStage`. The origin is the waypoint center on X and Z. Authored Y is kept. A local XZ outside the footprint throws.
- `shell/PlaySession.ts` — `PlaySession` and `PlaySessionLaunch`. The constructor takes a `SimulationCoordinator`, a `RenderFrameBuilder`, and the launch. It rejects a waypoint that falls outside its stage floor. `frame` accepts optional `reduceMotionAndFlashing` and a positive finite `aspect`, and passes the resident space origin into the frame. `getSpaceOrigin` is that origin. `focusSharesDrawnSpace` is false when the focus entity is not in that space, and the camera then stays on the stage center. `setFocusEntity` on an unknown id leaves the focus unchanged and returns `null` without resolving. A known id resolves before returning. The return is the previous `stageId` when the space changes, and `null` when no stage was resident, the space has no stage, or the space is unchanged. `clickFloor` takes world meters and selects the nearest waypoint in the focus entity's space within `1.5` m on XZ. `requestMove` and `requestPortalState` forward to the coordinator. `setFreeCamOffset` writes the camera offset only. `setCameraDeAnchored` is the debug free-cam flag for the next frame.
- `index.ts` — Public application layer barrel re-exporting `SimulationCoordinator`, `RenderFrameBuilder`, `PlaySession`, and all 3-Layer Visual Blueprint schemas/types.
