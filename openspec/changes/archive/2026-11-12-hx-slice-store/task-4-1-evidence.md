# Task 4.1 evidence — versioned slice save/load

Task 4.1 changes three production files plus focused tests and related guides. `StateSliceStore` records optional positive key versions, exposes raw values and version metadata separately, and migrates a known older value once from its saved version. `WorldState` retains a supplied immutable store. `SimulationCoordinator` binds an optional registry to effect writes and loads, saves `__upliftCustomSliceVersions` beside raw custom values, and prepares a validated store before publishing a loaded world or RNG.
