# Task 1.2 evidence — coordinator codec and durable save result

## Scope and observed checks

One source file changed: `SimulationCoordinator.ts`. It now encodes and decodes world fields through the domain codec, attaches raw custom slices and their version map separately, and publishes restored world, RNG and legacy state only after validation and the required `load_slot` record. It catches only a failed `save_slot` telemetry write after repository success. Repository failures still throw. Related application and domain guides and the shipped status wording in `DESIGN_NOTES.md` were updated.

The new file-backed consumer test was run before implementation: 4/4 tests failed on absent version markers, accepted nested corruption and a telemetry exception after a durable write. After implementation and review corrections, the named task verification passed **35/35 tests in 6 files** (`npx vitest run tests/unit/application/SimulationCoordinator tests/unit/infrastructure/FileSaveSlotRepository.test.ts`; 221 ms final focused run on this host). A current save's complete encoded world, RNG continuation, custom slice/value versions and legacy export survive file repository → new coordinator → resave/load. A synthetic version-one inner snapshot reaches the decoder once, remains version one on disk, and becomes version two on resave; the current-version load reaches the decoder with marker two. Corrupt nested fields and inner/outer epoch or tick mismatches preserve prior coordinator state and slot bytes and permit retry. Injected save telemetry failure returns the durable envelope; injected repository replacement failure preserves prior bytes and emits no successful save record.

The first sandboxed `npm run verify` failed lint/typecheck on two unused test constants and failed 32 HTTP tests because `listen` was denied with `EPERM` on `127.0.0.1`. The constants became asserted sidecars; final verification with loopback access passed: format **1,360 ms**, lint **1,283 ms**, typecheck **806 ms**, test **16,951 ms**. Strict OpenSpec validation passed. Checked defect reconciliation passed with **49 active, 30 resolved**. `git diff --check` and the scoped diff passed. These are current-host measurements; the 2019 Intel reference-Mac verification and per-save costs remain unmeasured.
